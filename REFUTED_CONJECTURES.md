# Refuted and retired conjectures

**Role:** the negative-results index. One entry per statement this programme
proposed and then killed, with the witness that killed it and where the killing
is written up.

**This list is partial.** Absence from this file is **not** evidence that a
route is alive. When you kill something, add it here.

**Why this file exists.** Re-proposing a refuted route is the most common way
to waste a session in a long conjecture programme. Read this before proposing a
mechanism.

**Authority.** [`master.tex`](master.tex) is the source of truth. Where an
entry below conflicts with it, the manuscript wins and this file is stale.
Entries are graded:

| grade | meaning |
|:--|:--|
| **P** | refuted by proof |
| **C** | refuted by an explicit verified counterexample or exact computation |
| **R** | not refuted — *retired*, because the statement collapsed to something already known, or was shown to be no easier than the target |
| **N** | claimed refuted, but the refutation is numerical extrapolation only; treat the statement as open |

A grade-**N** entry is still an open statement. It stays in this file so the
claim is on record, but it must not be cited as dead.
